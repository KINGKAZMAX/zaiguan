# 再观 Arena · 让观看留下痕迹

观展后的个人知识档案。形态复刻自 **Are.na**(are.na)—— 设计师最爱的"共同知识档案"平台:
把碎片内容收进个人频道,排版极简克制、编辑感强。纯静态 SPA,零构建零后端,
数据全部保存在浏览器 localStorage。

**线上地址**: <https://kingkazmax.github.io/zaiguan/>

## Are.na 的心智 → 再观实现

| Are.na | 再观 | 入口 |
|---|---|---|
| Block 块 | 一切皆块:50 件馆藏真迹、观展照片、裁剪细节、**文字碎片**、拼贴创作 | `#/` 探索流 |
| Channel 频道 | 自建频道(建/重命名/描述/删除/移出),3 个官方示例频道 | `#/channels` |
| **Connect 连接** | 任意块 hover「＋」或详情页「连接到频道」→ 多选频道弹层,可就地新建 | 全局 |
| Text block | 「＋」写下文字碎片(Times 衬线呈现,可进创作画布) | 顶栏 ＋ |
| 安静的流 | 多列瀑布流 + 小字注解(黑标题/灰元数据),无卡片边框 | `#/` |
| 搜索 | 顶栏全局搜索(标题/艺术家/媒介/馆藏) | 顶栏 |

## 打通的功能

- **裁剪细节**:块详情深度缩放(滚轮/拖动/双击)→ 虚线裁剪框 → 细节块入档案,可写一句注
- **创作 Make**:细节/馆藏/照片/文字碎片四类素材上画布,拖·缩·旋·图层·文字,680×906 PNG 导出
- **上传照片**:EXIF 拍摄时间 + 主色自动归入 10 色系,成为块参与一切流程
- **v4 → v5 自动迁移**:旧收藏集变频道,收藏/细节/创作/笔记原地保留
- 设置页:数据导出/导入/清空

## 素材

50 件藏品全部为 **Wikimedia Commons 真实影像**(公有领域/CC,含 Google Art Project、
Rijksmuseum 超高清夜巡、Prado 宫娥),经视觉模型逐张校验;断网自动回退程序化生成图。
作品详情页标注「来源」。
