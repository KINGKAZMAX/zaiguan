# 再观 Zaiguan

> **让观看发生第二次** —— 观展后个人文化记忆系统

面向"智艺未来:人工智能时代的艺术生产"论坛主题,聚焦 AI 赋能文化遗产知识生产、传播展示与教育转化:让观众零散的观展照片,转化为**可回顾、可理解、可持续积累**的个人文化档案。

**核心链路:上传照片 → 识别线索 → 记录感受 → 形成档案**

🔗 在线使用:[https://kingkazmax.github.io/zaiguan/](https://kingkazmax.github.io/zaiguan/)

## 功能特性

### 📒 观展记录库(记录)
- 以一次展览为单位建立"观展记录册":场馆、展览名称、参观日期
- 四步创建流程:基本信息 → 添加照片 → 识别线索 → 生成记录册
- 支持多张照片批量导入(自动压缩),也支持"空白展品卡"(没有照片也能先记录感受)

### 🔍 识别线索(模拟多模态识别 + 馆藏匹配)
- 内置 20 条馆藏知识库(故宫、三星堆、上博、奥赛、罗丹博物馆……)
- 模拟 AI 视觉特征提取与馆藏数据匹配,给出带置信度的**系统建议**
- **JPEG EXIF 拍摄时间解析**:自动读取照片的原始拍摄时间(纯前端实现)
- 人机边界清晰:AI 仅提供有来源、可修正的建议,**确认权在用户**

### 🃏 展品记录卡
- **观展语境**:场馆、展览、参观日期、照片拍摄时间
- **展品知识**:名称、作者/时代、媒介、类别、馆藏来源、信息来源
- **个人经验**:感受、五星评价、留下的问题、自定义标签、是否愿意公开
- **匹配状态机**:系统建议 → 已确认 / 已修改 / 待补充 / 未识别(用户修改知识字段后自动标记"已修改"并保留原建议来源)

### 🗂 个人文化档案(档案)
- 跨展览时间线,按月分组
- 多维筛选:类别、自定义标签、全文搜索(展品/艺术家/展览/感受)

### 🧭 兴趣线索(线索)
- 高频标签、媒介类别分布、年代分布、常相遇的创作者
- **跨展览洞察**:自动发现出现在 ≥2 次观展中的标签,呈现个人兴趣谱系

### ⚙️ 设置与数据管理
- 数据 100% 存储于浏览器本地(localStorage),零上传、零后端
- 一键导出/导入 JSON、导出单册、恢复示例数据、彻底清空
- 隐私与人机边界说明

## 技术实现

| 项 | 说明 |
|---|---|
| 架构 | 纯前端单页应用(SPA),无后端、无依赖、无构建 |
| UI | iOS 风格(底部标签栏、底部弹层、毛玻璃、开关、分段筛选),宣纸底色 + 朱砂印章视觉 |
| 存储 | localStorage + 照片 Canvas 压缩(最长边 1000px,JPEG 0.82) |
| EXIF | 自实现的 JPEG APP1/TIFF IFD 解析器,读取 `DateTimeOriginal (0x9003)` |
| 识别 | 确定性伪随机(mulberry32)模拟多模态识别,建议可复现 |
| 部署 | GitHub Pages 静态托管;iOS Safari「添加到主屏幕」即可类原生使用 |

## 本地运行

```bash
cd zaiguan
python3 -m http.server 8080
# 打开 http://localhost:8080
```

直接双击 `index.html` 也可以运行(照片读取使用 FileReader,无需服务器)。

## 项目结构

```
zaiguan/

├── style.css       # iOS 风格 UI 样式
└── js/
    ├── kb.js       # 馆藏知识库 / 类别配色 / EXIF 解析 / 示例数据

```

## 隐私

所有照片、感受与记录仅保存在你的浏览器本地,不会上传到任何服务器;你可以随时导出 JSON 备份,或彻底删除。AI 仅提供有来源、可修正的整理建议;评价、感受和意义,始终由观众本人表达和决定。
