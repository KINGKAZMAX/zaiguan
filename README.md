# 再观 Zaiguan

> **让观看发生第二次** —— 观展后个人文化记忆系统

面向"智艺未来:人工智能时代的艺术生产"论坛主题,聚焦 AI 赋能文化遗产知识生产、传播展示与教育转化:让观众零散的观展照片,转化为**可回顾、可理解、可持续积累**的个人文化档案。

**核心链路:上传照片 → 识别线索 → 记录感受 → 形成档案**

产品形态参考 **[Rijksmuseum Rijksstudio](https://www.rijksmuseum.nl/en/rijksstudio)**(博物馆界最佳 UX):以「收藏集 Collections」组织每次观展,支持像 Rijksstudio 一样**裁剪作品细节(Crop Details)**留作个人观看证据。

🔗 在线使用:[https://kingkazmax.github.io/zaiguan/](https://kingkazmax.github.io/zaiguan/)

## 功能特性

### 🗂 收藏集 Collections(信息架构复刻 Rijksstudio)
- 每次观展 = 一册收藏集(场馆、展览名称、参观日期),封面取首件作品,带数量角标与最爱徽章
- 四步创建:基本信息 → 添加照片 → 识别线索 → 生成收藏集
- 收藏集详情:作品瀑布流 + 完成度,可继续添加展品、导出单册

### ✂ 裁剪细节 Crop Details(Rijksstudio 标志性功能)
- 在作品页拖动框选照片任意局部,保存为"细节卡",可写一句注
- 细节画廊横向展示、点开大图查看/加注/删除
- 示例数据预置 6 处真实可裁细节(石青山头、中空的手、水面的光…)

### 🖼 全部作品 Artworks
- 瀑布流浏览所有展品,红色 ♥ 标记最爱、按最爱筛选
- 类别 / 标签 / 全文搜索多维筛选

### 🃏 作品卡(展品记录卡)
- **观展语境**:场馆、展览、参观日期、EXIF 拍摄时间
- **展品知识**:名称、作者/时代、媒介、类别、馆藏来源、信息来源(可修正)
- **个人经验**:感受、五星评价、问题、标签、是否公开
- **匹配状态机**:系统建议 → 已确认 / 已修改 / 待补充 / 未识别

### 🔍 识别线索(模拟多模态识别 + 馆藏匹配)
- 内置 20 条馆藏知识库,给出带置信度的系统建议,**确认权在用户**
- JPEG EXIF 拍摄时间纯前端解析

### 🧭 兴趣线索 & ⚙️ 数据管理
- 高频标签 / 媒介 / 年代分布、创作者排行、跨收藏集洞察、细节裁剪统计
- 数据 100% 本地(localStorage),JSON 导入导出、一键清空

## 技术实现

| 项 | 说明 |
|---|---|
| 架构 | 纯前端单页应用(SPA),无后端、无依赖、无构建 |
| UI | Rijksstudio 式编辑排版:白底、大衬线标题、黑框统计条、黑色按钮、红色爱心(设计说明见 [DESIGN.md](DESIGN.md)) |
| 字体 | 系统衬线栈 Songti SC / STSong / Noto Serif SC(零外部依赖,永远可加载) |
| 裁剪细节 | 原生 Pointer Events 拖选 + Canvas 裁切(暗角遮罩用 box-shadow 9999px 技巧) |
| 存储 | localStorage(`zaiguan.v2`,含 crops/favorite 字段迁移归一化)+ 照片 Canvas 压缩 |
| EXIF | 自实现 JPEG APP1/TIFF IFD 解析器,读取 `DateTimeOriginal (0x9003)` |
| 识别 | 确定性伪随机(mulberry32)模拟多模态识别,建议可复现 |
| 部署 | GitHub Pages 静态托管;iOS Safari「添加到主屏幕」即可类原生使用 |

## 本地运行

```bash
cd zaiguan
python3 -m http.server 8080
# 打开 http://localhost:8080
```

直接双击 `index.html` 也可以运行(照片读取使用 FileReader,无需服务器)。

## 项目结构

```
zaiguan/
├── index.html      # 入口与页面骨架
├── style.css       # Rijksstudio 式编辑排版样式
├── DESIGN.md       # 设计手册(Rijksstudio 复刻要点 + 中国风素材资源存档)
└── js/
    ├── kb.js       # 馆藏知识库 / 画布程序化展品图 / EXIF 解析 / 示例数据(含预置细节)
    └── app.js      # 收藏集与作品页 / 裁剪细节 / 四步创建 / 洞察 / 导入导出
```

## 隐私

所有照片、感受与记录仅保存在你的浏览器本地,不会上传到任何服务器;你可以随时导出 JSON 备份,或彻底删除。AI 仅提供有来源、可修正的整理建议;评价、感受和意义,始终由观众本人表达和决定。
